📸 Photographer Portfolio - Quick Start Guide

✨ What You Got:

  • ✅ Professional photographer portfolio website
  • ✅ Filterable gallery (Wedding, Graduation, Portrait, Event)
  • ✅ Responsive design (mobile, tablet, desktop)
  • ✅ Contact form
  • ✅ Services section
  • ✅ About section
  • ✅ Smooth animations

Step 1: Install Node.js

If you don't have Node.js installed:

  1. Go to https://nodejs.org
  2. Download and install the LTS version
  3. Restart your computer

Step 2: Open Terminal

Open Command Prompt or PowerShell in the project folder:

  1. Go to Desktop
  2. Right-click on "photographer-portfolio" folder
  3. Select "Open in Terminal" or "Open PowerShell window here"

Step 3: Install Dependencies

In the terminal, run:

npm install

Wait for installation to complete (may take 2-3 minutes)

Step 4: Start the Website

Run this command:

npm start

The website will automatically open in your browser at:

http://localhost:3000

🎯 Gallery Filtering Feature:

The gallery has filter buttons at the top:

  • All Photos - Shows everything
  • Weddings - Shows only wedding photos
  • Graduations - Shows only graduation photos
  • Portraits - Shows only portrait photos
  • Events - Shows only event photos

Click any button to filter the gallery instantly!

Step 5: Customize Your Portfolio

Add Your Own Photos:

  1. Open: src/components/Gallery.js
  2. Find the galleryItems array
  3. Replace image URLs with your photos
  4. Set the correct category for each photo

Change Contact Info:

  1. Open: src/components/Contact.js
  2. Update email, phone, and location

Update About Section:

  1. Open: src/components/About.js
  2. Change name, bio, and statistics

⚠️ Important Notes:

  • Keep the terminal window open while developing
  • Press Ctrl+C in terminal to stop the server
  • Changes auto-reload in the browser
  • Don't delete node_modules folder

Step 6: Build for Production

When ready to deploy:

npm run build

This creates a build folder with optimized files ready for hosting.

📁 Project Structure:

  • src/components/ - All React components
  • src/components/Gallery.js - Gallery with filtering ⭐
  • public/ - Static files
  • package.json - Project configuration

🎨 Customization Tips:

  • Main color is #e74c3c (red) - change in CSS files
  • Add more categories by editing Gallery.js
  • Update services and pricing in Services.js
  • Change hero background image in Hero.css
